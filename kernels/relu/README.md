# Relu

## 0x00 说明

本模块是 LeetCUDA `kernels/relu` 的 Intel oneAPI/SYCL 移植版本，包含：

- [X] `relu_f32`：FP32 标量版（SYCL，每 work-item 1 个元素）
- [X] `relu_f32x4`：FP32 向量化版（`sycl::vec<float,4>`，16 字节访存）
- [X] `relu_f16`：FP16 标量版（`sycl::half`）
- [X] `relu_f16x2`：FP16 每 work-item 2 元素（4 字节访存）
- [X] `relu_f16x8`：FP16 每 work-item 8 元素（4 次 4 字节访存，unpack）
- [X] `relu_f16x8_pack`：FP16 每 work-item 8 元素（128 位打包访存）
- [X] PyTorch XPU bindings

计算公式：`y[i] = max(0, x[i])`。relu 是**单输入算子**，与 elementwise
（`c = a + b`）相比少读一份数据；与 sigmoid 相比少了一次 `exp` 与一次除法——
整个算子只有一次取最大值，因此本模块也是观察**显存带宽上限**的最佳样本。

代码文件：

| 文件 | 作用 |
| --- | --- |
| `relu.sycl` | SYCL kernel + PyTorch XPU 绑定（对应 CUDA 版 `relu.cu`） |
| `relu.py` | 用 `torch.utils.cpp_extension.load` 编译 `.sycl` 并执行基准测试 |

> 说明：本模块严格照搬 CUDA 版的算法与启动配置，**包括**已知缺陷——
> `relu_f32x4` / `relu_f16x2` / `relu_f16x8` 只判断段首下标、缺少 tail 分支
> （`N` 不是向量宽度整数倍时会越界写），`relu_f16x8_pack` 尾部不足 8 个元素的
> 整段会被直接漏算。基准测试的 `S`、`K` 都是 256 的倍数，不会触发这些问题。
> 详见 `../../docs/kernels/relu/README.md`。

## 测试

先按 `../../scripts/README.md` 完成环境搭建（Intel oneAPI 容器 + Python venv +
PyTorch XPU），然后运行：

```bash
# 进入 oneAPI 容器后手动执行（命令详见 ../../scripts/README.md）
sudo docker start leetoneapi
sudo docker exec -it leetoneapi /bin/bash

cd /workspace/LeetOneAPI
source .venv/bin/activate
cd /workspace/LeetOneAPI/kernels/relu
python3 relu.py
```

默认 `relu.py` 使用 JIT（仅 spir64）编译，避免基础镜像缺少 ocloc 时 AOT 失败。
仅当已安装 ocloc/离线 GPU 编译器且需要 AOT 时，才自行设置：

```bash
export TORCH_XPU_ARCH_LIST="xe-hpg"  # 按实际架构填写，如 pvc、bmg 等
python3 relu.py
```

判断标准：

- 同一次运行的 FP32 三个输出前 2 个元素应一致（`f32` / `f32x4` / `torch f32`）；
- 同一次运行的 FP16 各版本输出前 2 个元素应一致（`f16` / `f16x2` / `f16x8` /
  `f16x8pack` / `torch f16`）；
- FP16 与 FP32 允许有约 `1/1024` 量级的量化误差，这是半精度本身的精度损失
  （ReLU 是“原样返回或清零”，误差不会被放大，只来自输入从 FP32 转 FP16 那一步）；
- 所有结果都应落在 `[0, +∞)`，负输入被清成 `0`，不应出现 `NaN` / `inf`；
- 随机输入的前两个元素可能本来就是负数，被 ReLU 截成 `0`（打印为 `0.0` 或
  `0`），属正常现象，不代表 kernel 出错。

## CUDA → SYCL 速查

| CUDA | oneAPI / SYCL |
| --- | --- |
| `relu.cu` + nvcc | `relu.sycl` + `icpx -fsycl` |
| `kernel<<<grid, block>>>(args)` | `queue.submit` + `parallel_for(nd_range)` |
| `blockIdx.x * blockDim.x + threadIdx.x` | `item.get_global_id(0)` |
| `float4` / `half2` | `sycl::vec<float,4>` / `sycl::vec<sycl::half,2>` |
| `fmaxf(0.0f, x)` | `sycl::fmax(0.0f, x)` |
| `__hmax` / `__hmax2` | `sycl::fmax`（half 标量 / `sycl::vec<sycl::half,2>` 重载） |
| `__float2half(0.0f)` | `sycl::half(0.0f)` |
| `torch.cuda` / `.cuda()` | `torch.xpu` / `.xpu()` |
| `TORCH_CUDA_ARCH_LIST` | `TORCH_XPU_ARCH_LIST` |

详细设计说明见 `../../docs/kernels/relu/README.md`。
