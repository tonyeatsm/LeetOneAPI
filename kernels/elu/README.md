# Elu

## 0x00 说明

本模块是 LeetCUDA `kernels/elu` 的 Intel oneAPI/SYCL 移植版本，包含：

- [X] `elu_f32`：FP32 标量版（SYCL，每 work-item 1 个元素）
- [X] `elu_f32x4`：FP32 向量化版（`sycl::vec<float,4>`，16 字节访存）
- [X] `elu_f16`：FP16 标量版（`sycl::half`）
- [X] `elu_f16x2`：FP16 每 work-item 2 元素（4 字节访存）
- [X] `elu_f16x8`：FP16 每 work-item 8 元素（4 次 4 字节访存，unpack）
- [X] `elu_f16x8_pack`：FP16 每 work-item 8 元素（128 位打包访存）
- [X] PyTorch XPU bindings

计算公式：`y[i] = x > 0 ? x : alpha * (exp(x) - 1)`（本模块 `alpha = 1.0`）。
ELU 是**单输入算子**：正半轴和 ReLU 一样是恒等映射，负半轴像 sigmoid 一样
指数饱和到 `-alpha`，但**指数只出现在负半轴**，所以不需要 `clamp` 溢出保护。

代码文件：

| 文件 | 作用 |
| --- | --- |
| `elu.sycl` | SYCL kernel + PyTorch XPU 绑定（对应 CUDA 版 `elu.cu`） |
| `elu.py` | 用 `torch.utils.cpp_extension.load` 编译 `.sycl` 并执行基准测试 |

> 说明：本模块严格照搬 CUDA 版的算法与启动配置，**包括**已知缺陷——
> `elu_f32x4` / `elu_f16x2` / `elu_f16x8` 只判断段首下标、缺少 tail 分支
> （`N` 不是向量宽度整数倍时会越界写），`elu_f16x8_pack` 尾部不足 8 个元素的
> 整段会被直接漏算。基准测试的 `S`、`K` 都是 256 的倍数，不会触发这些问题。
> 详见 `../../docs/kernels/elu/README.md`。

## 测试

先按 `../../scripts/README.md` 完成环境搭建（Intel oneAPI 容器 + Python venv +
PyTorch XPU），然后运行：

```bash
# 进入 oneAPI 容器后手动执行（命令详见 ../../scripts/README.md）
sudo docker start leetoneapi
sudo docker exec -it leetoneapi /bin/bash

cd /workspace/LeetOneAPI
source .venv/bin/activate
cd /workspace/LeetOneAPI/kernels/elu
python3 elu.py
```

默认 `elu.py` 使用 JIT（仅 spir64）编译，避免基础镜像缺少 ocloc 时 AOT 失败。
仅当已安装 ocloc/离线 GPU 编译器且需要 AOT 时，才自行设置：

```bash
export TORCH_XPU_ARCH_LIST="xe-hpg"  # 按实际架构填写，如 pvc、bmg 等
python3 elu.py
```

判断标准：

- 同一次运行的 FP32 三个输出前 2 个元素应一致（`f32` / `f32x4` / `torch_elu`）；
- 同一次运行的 FP16 各版本输出前 2 个元素应一致（`f16` / `f16x2` / `f16x8` /
  `f16x8pack` / `torch_elu`）；
- FP16 与 FP32 允许有约 `1/1024` 量级的量化误差；负半轴靠近 0 的位置还会叠加
  `exp(x) - 1` 的相减抵消，误差相对更大；
- 所有结果都应落在 `(-1, +∞)`（`alpha = 1`），负半轴输出是负值而不是 0；
- 对照实现 `torch_elu` 由多个算子拼成，`out_*_th` 偏慢属正常现象
  （详见 `../../docs/kernels/elu/README.md`）。

## CUDA → SYCL 速查

| CUDA | oneAPI / SYCL |
| --- | --- |
| `elu.cu` + nvcc | `elu.sycl` + `icpx -fsycl` |
| `kernel<<<grid, block>>>(args)` | `queue.submit` + `parallel_for(nd_range)` |
| `blockIdx.x * blockDim.x + threadIdx.x` | `item.get_global_id(0)` |
| `float4` / `half2` | `sycl::vec<float,4>` / `sycl::vec<sycl::half,2>` |
| `x > 0.f ? x : ALPHA * (expf(x) - 1.f)` | `x > 0.0f ? x : ALPHA * (sycl::exp(x) - 1.0f)` |
| `__hgt` / `__hmul` / `__hsub` / `hexp` | half 的 `>` / `*` / `-` 与 `sycl::exp` |
| `__float2half(1.0f)` | `sycl::half(1.0f)` |
| `torch.cuda` / `.cuda()` | `torch.xpu` / `.xpu()` |
| `TORCH_CUDA_ARCH_LIST` | `TORCH_XPU_ARCH_LIST` |

详细设计说明见 `../../docs/kernels/elu/README.md`。
